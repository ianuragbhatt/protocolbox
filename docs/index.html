Web Tools

Utilities for interacting with the live internet.

scrape (url: str) → str

Fetches a URL, removes scripts/styles/ads, and converts content to clean Markdown. 90% token reduction on average.

# Agent Usage
result = scrape("https://example.com/article")
web_search (query: str, max_results: int = 3) → str

Privacy-focused web search via DuckDuckGo. Returns Markdown-formatted results with titles, links, and snippets. No API key required.

# Agent Usage
result = web_search("latest MCP protocol updates", max_results=5)
get_transcript (video_url: str) → str

Fetches the English transcript of a YouTube video as clean text. Supports standard, short (youtu.be), and embed URL formats.

# Agent Usage
result = get_transcript("https://youtu.be/dQw4w9WgXcQ")

Logic & Math

Reliable computation and data structuring without code injection.

safe_math (expression: str) → str

Securely evaluates mathematical expressions using AST parsing — zero eval(). Supports arithmetic (+, -, *, /, **, %) and functions (sqrt, floor, ceil, abs, sin, cos, tan, log).

# Agent Usage
result = safe_math("sqrt(144) + 2 ** 3") # → "20.0"
heal_json (broken_json: str) → dict

Repairs common JSON syntax errors generated by LLMs — trailing commas, unquoted keys, single quotes, and truncated output.

# Agent Usage
result = heal_json("{'name': 'Alice', 'age': 30,}") # → {"name": "Alice", "age": 30}
