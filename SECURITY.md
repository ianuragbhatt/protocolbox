# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in ProtocolBox, please report it privately.

**DO NOT** open a public issue.

Instead, please email **anurag@protocolbox.in** with:

- A description of the vulnerability.
- Steps to reproduce.
- Potential impact.

We will acknowledge your report within 48 hours and strive to fix critical issues promptly.
